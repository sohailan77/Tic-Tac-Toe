# Tic-Tac-Toe

A responsive Tic Tac Toe web game built using vanilla HTML, CSS, and JavaScript. Designed to adapt seamlessly across mobile, tablet, and desktop screens with smooth, interactive turn-based gameplay.

---

## ✨ Features

* **Responsive Design:** Scales smoothly for mobile phones, tablets, and desktop monitors.
* **Two-Player Mode:** Classic local X vs. O turn-based gameplay.
* **Win & Draw Detection:** Automatically highlights winning combinations or declares a draw.
* **Instant Reset:** Quickly restart the board for a new match without reloading the page.

---

## 🛠️ Built With

* **HTML5** – Semantic structure for the game board and controls.
* **CSS3** – Flexbox/Grid layout and responsive media queries.
* **JavaScript (ES6)** – Game state logic, DOM manipulation, and win-condition checks.
